# JSON Parsing
Parsing hierarchical JSON structures using Python dictionaries and lists.

## Pipeline

```text
 Read
   ↓
Inspect
   ↓
Traverse
   ↓
 Clean
   ↓
Validate
   ↓
 Extract
   ↓
 Flatten
   ↓
 Export
```

## Concepts Learned

- `json.load()` / `json.loads()`
- `json.dump()` / `json.dumps()`
- Schema inspection
- Hierarchical JSON traversal
- Nested dict and list access
- Safe access with `.get()`
- Null handling (`null` → `None`)
- Cleaning and normalization
- Validation pipelines
- Datetime validation
- Filtering and extraction
- Flattening nested JSON
- Structured parsing pipelines
