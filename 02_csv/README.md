# CSV Parsing
Parses a dirty sales CSV through a full pipeline:

- inspects schema before processing
- cleans and validates each row
- filters, sorts, and analyzes cleaned data
- exports results to CSV and JSON

## Concepts Learned

- CSV parsing with `csv.DictReader`
- Schema inspection
- Data cleaning and validation
- Missing value handling
- Duplicate detection
- Date and numeric validation
- Filtering and sorting structured data
- Aggregation and grouping
- CSV and JSON exporting
- Structured data pipeline design
